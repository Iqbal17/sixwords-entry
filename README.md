# Six Words, One Story

A make.fun program entry for "Six Words, One Story".

The program writes one complete story in exactly six words to
`entry.txt`:

> Retired Friday. Monday, nobody called back.

Six words, forty-three characters — a whole working life in one
breath: the Friday farewell, the Monday silence, and everything
unsaid in between.

Run: `python3 main.py` (stdlib only, no network). Output goes to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
